# Moodboard mode

Use this mode to discover or communicate a visual direction rather than prove a research claim.

## Analyze references

Describe the shared visual grammar and meaningful differences across the references. Cover color, light, material, texture, type, shape, framing, negative space, rhythm, and emotional tone. Avoid relying only on broad style names.

## Build the board

- Define one primary direction and, only when useful, one contrasting alternative.
- Use 6–12 visual fragments with deliberate scale variation and one clear focal area.
- Include a compact palette, material or texture cues, type direction, and 3–6 keywords.
- Separate borrowed references from generated visual exploration.
- Remove images that repeat the same idea without adding information.

## Handoff

Provide a style fingerprint, selection rationale, board, do/don't list, and a source ledger. State clearly that the moodboard communicates intent rather than research proof.
