# Collage Studio

Turn reference images, research material, and project text into a visually coherent collage while keeping facts separate from interpretation. Work in Chinese unless the user requests another language.

## Select a mode

- **Moodboard** — establish visual direction from references, keywords, atmosphere, materials, color, typography, and composition. Read [references/moodboard.md](references/moodboard.md).
- **Research Collage** — synthesize fieldwork and research without fabricating evidence. Read [references/research-collage.md](references/research-collage.md).
- **Portfolio Collage** — compose portfolio-ready pages that explain project logic and process. Read [references/portfolio-collage.md](references/portfolio-collage.md).

If the user does not name a mode, infer it from the intended outcome. Ask only when different modes would produce materially different deliverables.

## Shared workflow

1. Collect the available inputs: reference images, research artifacts, project text, target audience, page size or aspect ratio, output language, and any must-keep or must-avoid elements. Do not claim to have inspected files that were not provided or accessible.
2. Inspect every supplied image before drawing conclusions. Record observable qualities first: palette, contrast, density, scale, grid, cropping, typography, texture, material, visual rhythm, and focal hierarchy.
3. Keep a source ledger and apply the labels in [references/evidence-boundaries.md](references/evidence-boundaries.md). Never present a visual inference or AI-generated element as real research evidence.
4. Propose a concise art direction before generation: one-sentence intent, 3–6 style keywords, palette, composition system, image treatment, and exclusions.
5. Build the collage. When bitmap generation or image editing is needed, use the available image-generation workflow. Preserve important source content, request an appropriate aspect ratio, and avoid adding unsupported documentary details.
6. Arrange text and imagery with a clear reading order. Prefer short captions tied to specific evidence over decorative paragraphs. Preserve legibility at the intended output size.
7. Review the result for provenance, hierarchy, consistency, accessibility, and portfolio relevance. Revise once when an obvious problem is found.

## Required handoff

Deliver the collage or editable layout plus:

- selected mode and intended use;
- visual direction summary;
- source ledger with evidence labels;
- layout map or reading order;
- editable copy for titles and captions;
- a short note identifying assumptions, missing evidence, and suggested next iteration.

Do not invent participants, quotes, dates, locations, observations, test outcomes, citations, or project results. Keep AI-generated imagery visibly labeled in teaching and portfolio contexts.
